💻 CPU Instruction Cycle Simulator

An interactive, web-based educational simulator that demonstrates how a Central Processing Unit (CPU) processes instructions through the Fetch, Decode, and Execute cycle. Built using HTML, CSS, and JavaScript, this project helps students understand fundamental computer architecture concepts through visualization.

📌 About the Project

The CPU Instruction Cycle Simulator is designed to make computer organization and architecture easier to understand. Instead of learning only through theoretical explanations, users can explore the basic stages of instruction execution using a simple web interface.

The simulator illustrates how the CPU fetches an instruction from memory, decodes it to identify the required operation, and executes that operation. It is suitable for students, beginners, and anyone interested in understanding the internal working of a processor.

🎯 Objectives

- Understand the fundamental CPU instruction cycle.
- Demonstrate the Fetch, Decode, and Execute stages.
- Explain the role of the Program Counter (PC) and Control Unit.

🔄 Understanding the Instruction Cycle

1. Fetch

The CPU retrieves the next instruction from memory. The Program Counter (PC) identifies the address of the instruction to be fetched.

2. Decode

The Control Unit interprets the fetched instruction and determines which operation needs to be performed.

3. Execute

The CPU performs the specified operation. Depending on the instruction, this may involve arithmetic, logical operations, data movement, or another supported action.

These stages form the basic instruction cycle. Actual processors may use additional stages and advanced execution techniques.
